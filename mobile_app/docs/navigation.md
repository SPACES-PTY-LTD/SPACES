# Native delivery guidance

Google Navigation SDK is pinned at 0.16.3 for this app's Expo 57 / React Native 0.86. It requires native builds; Expo Go/web and older binaries retain preview with Start disabled. `SPACES_NAVIGATION_ENABLED=false` disables guidance at build-config/runtime level but retains the native dependency.

Supply restricted `GOOGLE_MAPS_IOS_API_KEY` and `GOOGLE_MAPS_ANDROID_API_KEY` through the existing build environment. Enable the corresponding Navigation SDK, Maps platform services and billing for their project; restrict keys to the app bundle/application identifiers. Never commit keys. No Laravel API/database change is required for guidance; the existing phone-origin preview endpoint must already be deployed.

From `mobile_app`, run `npm ci`, `npx expo prebuild --no-install`, then `npm run ios` or `npm run android` with Xcode/CocoaPods or a compatible Android SDK/JDK available. The iOS preview uses MapKit; guidance uses Google Navigation. Android Navigation supplies the Maps classes, so the config plugin substitutes the standalone Maps dependency with Navigation 7.6.1 on every consumer compile/runtime classpath. Review Google SDK license/terms prompts and platform key restrictions in the built application.

Local verification on 2026-10-10: Expo prebuild, TypeScript, focused navigation lint and 28 targeted tests pass. CocoaPods failed while unpacking ExpoModulesCore because disk space was exhausted. Android Gradle could not start: JAVA_HOME points to a missing Android Studio JBR and no Java installation was detected. iOS native compilation subsequently passed in EAS build dd790d83. Android compilation and both platforms’ physical runtime behavior remain **unverified**. Free disk space/configure the JDK for local builds, or use EAS before enabling this in production.

Physical acceptance: grant/deny foreground, Always/background and notifications; accept/refuse Google terms; cancel/retry initialization; use zero/invalid coordinates; drive off-route; test mute, Bluetooth, recenter, ETA, arrival and Exit; switch tabs and lock/background the phone; log out/change/end the run; complete/remove the delivery; exercise large text, dark mode and all draggable sheet positions. Confirm controls and Google attribution remain visible. Exit returns to preview; arrival does not deliver the shipment/end the run. Dispatch-sharing permission remains independent. Process death never auto-restarts a session. Native background behavior and store permission declarations must be verified on both platforms before release.
